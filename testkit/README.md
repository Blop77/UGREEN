# Test kit

A small fake course for testing `lecture-revision-kit` on a real UGREEN AI NAS in Round 2. It is not part of the Skill package.

- `Operating Systems/`: the course folder to upload to the NAS.
- `add-later/`: copy this lecture into the course folder during the repeat-use test.
- `recording-scripts.md`: read these aloud to make the two lecture recordings.
- `generate.py`: rebuilds the slides, board photos and video (`python3 testkit/generate.py`).

The test steps and expected results are in [docs/round2-test-plan.md](../docs/round2-test-plan.md).
